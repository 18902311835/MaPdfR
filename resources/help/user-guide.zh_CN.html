MaPdfR 用户说明书

阅读、查找、复制和审阅 PDF。按 F1 可随时打开本说明书。

打开与浏览 · 选择与复制 · 查找 · 打印与审阅 · 保存与导出 · 快捷键 · 常见问题

打开与浏览

  1. 按 Ctrl+O 选择文件，可一次选择多份 PDF，也可以把 PDF 拖入阅读器。从资源管理器再次打开 PDF 时，文件会送到已运行的同一份 MaPdfR。
  2. 每份 PDF 在窗口顶部有一个标签。点击标签，或用 Ctrl+Tab／Ctrl+Shift+Tab 切换。重新打开同一路径会切到原标签。
  3. 按 Ctrl+W 或点标签右侧的 × 关闭当前文档。关闭全部标签后，可在原窗口继续打开文件。
  4. 加密 PDF 会要求输入密码。打开后，在窗口上方输入页码并按 Enter，或用 Page Up／Page Down 翻页。
  5. 用导航面板的「书签」打开章节，用「页面」查看缩略图。F4 显示或隐藏面板，Alt+← 和 Alt+→ 浏览前后位置。
  6. 工具栏可放大、缩小、适合宽度和适合整页。在「视图」切换单页或连续页面。F11 进入或退出全屏。

按 Ctrl+D 查看文件路径、页数、作者及 PDF 生成器等属性。属性值来自文档及本地文件信息。

选择与复制文本

  1. 在 PDF 页面找到所需文字。把鼠标放在起始字附近，按住左键，拖到同一页的末尾字附近再松开。高亮表示所选范围。
  2. 页面有焦点时按 Ctrl+C，或右击选择「复制所选文本」。也可使用「编辑 → 复制所选文本」。
  3. 在目标应用按 Ctrl+V 粘贴。点击页面空白处可清除选区。

复制为纯文本。换行和文字顺序取决于 PDF 的文本层。跨页内容请逐页复制。需要整页时，可用「编辑 → 复制当前页文本」。

某些 PDF 限制复制，状态栏会提示原因。Qt-only 构建仍可拖选和查看高亮，复制操作需要启用 MuPDF 的构建来校验权限。

查找文本

按 Ctrl+F 输入关键词，阅读区会高亮命中。按 F3／Shift+F3 浏览下一个／上一个匹配。Ctrl+Shift+F 打开带页码和上下文的结果列表。按 Esc 关闭查找栏。

打印与审阅

按 Ctrl+P 选择系统打印机。在打印对话框中选择全篇、当前页或页码范围及纸张方向，选项以驱动显示为准。页面等比缩放到纸张可打印区域。受限 PDF 可能禁止打印或仅允许低清打印。

使用「审阅 → 查看当前页便笺」读取已有便笺。要新增便笺，选择「审阅 → 添加便笺并保存副本」，在页面预览中点击放置位置，填写正文，然后另存新 PDF。可切换到新副本继续审阅。签名字段、文档级认证或批注限制可能阻止保存批注副本。

另存与导出

  • Ctrl+S 另存原 PDF，保留文档原有结构与密码设置。
  • Ctrl+M 导出 Markdown。输出包含提取出的文字结构，提取到的图片保存在同目录的 文件名_assets 文件夹。已有同名目录时，新目录会带后缀。请同时保留 Markdown 和它引用的图片目录。
  • 打印、便笺、复制和 Markdown 导出需要启用 MuPDF。Linux 的 Qt-only 构建提供阅读、搜索、导航和另存。

常见问题

  • 文字无法选择或搜索。 扫描 PDF 可能只有页面图片。请使用已有文本层的 PDF，或先用 OCR 工具生成文本层。
  • 文件已被修改。 如果另一个程序替换或移动了源文件，在 MaPdfR 中重新打开后再复制、打印或导出。
  • 复制内容换行异常。 复杂表格、多栏或特殊字体的文本顺序可能与页面视觉结构不同。分段复制后核对结果。
  • 如何设置 Windows 默认阅读器？ 在「帮助」下注册 PDF 文件类型，再使用「设为默认 PDF 打开程序」打开 Windows 的系统选择对话框。
